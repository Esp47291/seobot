# Copy system — Job Inside

Тон: спокойный, конкретный, взрослый. Как хороший прораб: что сделать, что будет дальше, сколько ждать.  
Не: капс, «пассивный доход», «гарантия рейтинга», фейковые цифры.

## Голос

- Коротко: 1 мысль на сообщение.
- Глаголы: «Откройте», «Пришлите», «На балансе».
- Деньги — только с единицами и статусом («130 ₽, после проверки»).
- Отказ — факт + следующий шаг, без унижения.
- Площадки: не учим обходить правила. Говорим про качество, свой опыт, свой город.

## Словарь

| Говорим | Не говорим |
|---|---|
| Задание, слот, проверка, баланс, заявка на вывод | Накрутка, гарантия звёзд, «алгоритм не заметит» |
| Принято / не приняли, причина | «Вы забанены за накрутку» без фактов |
| Обычно проверяем в рабочие часы | «Мгновенно», если это неправда |
| Процент с **принятых** заданий приглашённых | Пассивный доход, кэшбэк за вход |
| На балансе / заявка на вывод / перевели | «Принят и оплачен», если credited ещё нет |
| Свой опыт, визит в городе точки, проверка скрина | «Платим ВАМ за отзывы», готовый текст «вставьте это» |
| Слоты и правила в канале | Прокси/секрет в правилах; «алгоритм не заметит» |

## Примеры (готовые к вставке)

### Приветствие /start (цель)

```
Job Inside — локальные задания на картах и прозрачная оплата после проверки.

Исполнитель: выбираете слот, сдаёте скрины, видите баланс.
Бизнес: напишите нам — разберём точку и формат работы.

Кто вы?
[Хочу задания]  [Я представляю бизнес]
```

### Карточка задания

```
Яндекс Карты · Краснодар · кафе
Оплата: 130 ₽ после проверки
Что сделать: по инструкции на точке оставить свой отзыв о реальном визите.
Доказательство: скрин опубликованного отзыва.

[Открыть инструкцию]  [Начать]  [Другое задание]
```

Цена 130 — default кода `min_review_price_yandex`, не обещание рынка. В проде подставлять `task.price`.

### Отказ модерации

```
Не приняли заявку #{id}.
Причина: на скрине не видно дату/карточку заведения.

Можно сдать исправленный скрин или взять другое задание.
[К заданиям]  [Написать в поддержку]
```

### Успех выплаты

```
Перевели {amount} ₽ по заявке #{wd_id}.
На балансе осталось {balance} ₽.

Спасибо за аккуратную работу.
[К заданиям]  [Кабинет]
```

Факт patch-15: `admin:wd_paid` / `mgr:wd_paid` шлют «✅ Ваша заявка на вывод выплачена.» — **без суммы и остатка**. Дневной патч: подставить `wd.amount` и баланс после `mark_paid`.

### Реферал

```
Ваша ссылка: {link}

Если человек впервые откроет бота по ней и ему начислят оплату за принятое задание — вам 20% от этой оплаты. С приглашённого им — 5%.

Не за вход. За принятую работу.
Приглашено: {n} · из них с оплатой: {q} · начислено: {sum} ₽
```

`n`, `q` — в UI ещё нет. Пока можно только `{sum}` из кода.

### После сдачи скрина

```
Скрин получил, заявка #{id} в проверке.
Обычно смотрим в рабочие часы. Напишу сюда, как решим.
Пока лучше не присылать тот же кадр второй раз.
```

ETA без медианы из БД не выдумывать.

### Голос vs тон

Голос один (прораб). Тон — по моменту (NN/g: доверие важнее «дружелюбия»; UI Craft: ошибка без «!» и без юмора).

| Контекст | Тон | Паттерн | Не |
|---|---|---|---|
| /start, правила | Ясный | 1 мысль + 2 кнопки роли | Простыня оффера + реф + прокси |
| Карточка / инструкция | Конкретный | Площадка, город, цена, доказательство | «Легкие деньги», диктовка текста отзыва |
| Сдал скрин | Спокойный | id заявки + «в проверке» + рабочие часы | «Ожидайте» без якоря |
| Отказ / блок | Честный | Причина + следующий шаг | Капс, вина, «забанены за накрутку» |
| Деньги | Сдержанный | Сумма + статус (баланс / заявка / перевод) | «Принят и оплачен», если credited нет |
| Реферал / канал | Честный | % с accepted; процесс, не товар | Пассив, «платим за отзывы» |
| Пусто | Действие | Город + «напишем, когда слот» | Тупик «нет заданий» |

Деньги и отказ — high-stress: называть факт, не праздновать рутину (fintech copy: ETA бьёт «мы всё видим»).

### Граница площадок — в каждом публичном тексте

Google Maps UGC: нельзя стимулировать отзыв оплатой/скидкой и нельзя диктовать содержание. Job Inside не спорит «у нас другая схема». Публичный язык = **процесс проверки локальной работы**, не SKU «отзыв». Скрипт 1 и канал — та же граница. Prebuilt текст/фото исполнителю в `admin:allow` — не копирайт, а риск stuffing (скрипт 15); в COPY-01 **не слать** блок «Готовый текст для отзыва».

### Правила — готово к вставке (без прокси)

Заменить `RULES_TEXT`. Кнопка одна: «Принять правила». Кнопку прокси **удалить**. URL/секрет вынести в settings (дневной tech, не в текст).

```
Job Inside — локальные задания на картах.

Берём работу, если это ваш опыт в городе точки.
Не берём: чужой текст, накрутку рейтинга, обход правил площадок.

Как проходит слот
1. Карточка: площадка, город, цена, что сдать.
2. Скрин по инструкции.
3. Проверка. Оплата — на баланс после принятия, не в момент сдачи.
4. Вывод — заявкой, когда на балансе есть сумма (минимум в кабинете).

Реферал: доля с принятых заданий людей по вашей ссылке. Не за вход.

Канал новостей — слоты и правила, не проверка подписки.
[Принять правила]
```

Мин. вывод и % 20/5 в правила не дублировать цифрами, если settings могут смениться — «в кабинете / в реферальном экране». Если оставляем % — те же, что `task_payout.py` (20 / 5), не выдумывать.

### Пустые состояния и ошибки

```
В {город} сейчас нет слотов на {площадка}.
Не спамим. Когда появится — напишем сюда.
[Другой город]  [В меню]
```

`{город}` — из выбора `venue_city`, не выдумывать. Если город пустой: «По выбранным фильтрам слотов нет.»

Некорректный ввод (уже близко к делу): «Выберите город кнопками» — ок. Не «не понял».

Блок:

```
Доступ закрыт. Если это ошибка — напишите в поддержку из меню «Помощь».
```

@ владельца не хардкодить в общий текст, если есть `SUPPORT_URL`.
