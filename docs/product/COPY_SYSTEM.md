# Copy system — Job Inside

Тон: спокойный, конкретный, взрослый. Как хороший прораб: что сделать, что будет дальше, сколько ждать.  
Не: капс, «пассивный доход», «гарантия рейтинга», фейковые цифры.

## Голос

- Коротко: 1 мысль на сообщение.
- Глаголы: «Откройте», «Пришлите», «На балансе».
- Деньги — только с единицами и статусом («130 ₽, после проверки»).
- Отказ — факт + следующий шаг, без унижения.
- Площадки: не учим обходить правила. Говорим про качество, свой опыт, свой город.

## Словарь

| Говорим | Не говорим |
|---|---|
| Задание, слот, проверка, баланс, заявка на вывод | Накрутка, гарантия звёзд, «алгоритм не заметит» |
| Принято / не приняли, причина | «Вы забанены за накрутку» без фактов |
| Обычно проверяем в рабочие часы | «Мгновенно», если это неправда |
| Процент с **принятых** заданий приглашённых | Пассивный доход, кэшбэк за вход |

## Примеры (готовые к вставке)

### Приветствие /start (цель)

```
Job Inside — локальные задания на картах и прозрачная оплата после проверки.

Исполнитель: выбираете слот, сдаёте скрины, видите баланс.
Бизнес: напишите нам — разберём точку и формат работы.

Кто вы?
[Хочу задания]  [Я представляю бизнес]
```

### Карточка задания

```
Яндекс Карты · Краснодар · кафе
Оплата: 130 ₽ после проверки
Что сделать: по инструкции на точке оставить свой отзыв о реальном визите.
Доказательство: скрин опубликованного отзыва.

[Открыть инструкцию]  [Начать]  [Другое задание]
```

Цена 130 — default кода `min_review_price_yandex`, не обещание рынка. В проде подставлять `task.price`.

### Отказ модерации

```
Не приняли заявку #{id}.
Причина: на скрине не видно дату/карточку заведения.

Можно сдать исправленный скрин или взять другое задание.
[К заданиям]  [Написать в поддержку]
```

### Успех выплаты

```
Перевели {amount} ₽ по заявке #{wd_id}.
На балансе осталось {balance} ₽.

Спасибо за аккуратную работу.
[К заданиям]  [Кабинет]
```

Сейчас ближе к «💰 Выплата выполнена. Спасибо за работу!» — заменить, когда будет сумма в хендлере.

### Реферал

```
Ваша ссылка: {link}

Если человек впервые откроет бота по ней и ему начислят оплату за принятое задание — вам 20% от этой оплаты. С приглашённого им — 5%.

Не за вход. За принятую работу.
Приглашено: {n} · из них с оплатой: {q} · начислено: {sum} ₽
```

`n`, `q` — в UI ещё нет. Пока можно только `{sum}` из кода.

### После сдачи скрина

```
Скрин получил, заявка #{id} в проверке.
Обычно смотрим в рабочие часы. Напишу сюда, как решим.
Пока лучше не присылать тот же кадр второй раз.
```

ETA без медианы из БД не выдумывать.

## Сообщения, которые стоит переписать в коде (issue-style)

1. Rules: убрать прокси-секрет и тон «платим ВАМ за отзывы» → сервис локальных заданий + правила качества.
2. Рефералка: снять капс и «пассивный доход».
3. Пусто: не «нет заданий», а город + ожидание слота.

Полный рерайт всех строк — не этот час.
