## Уже лучше, чем master — не откатывать

- Баланс и вывод вместо «реквизиты на каждое задание»
- Reply-меню вместо только inline «взять»
- История отзывов и операций
- Менеджер, аналитика, CSV, docker
- Напоминание «можно снова»
- Город точки (качество/гео, не «обход»)

## Следующий gap после UX (очередь часов)

H2 (этот run): карта вставок + SQL-прокси — **не** код. Следующий продукт-час после ротации: H3 лендинг. AN-01 (3 лога) — дневной маленький PR, не ночной.

Дописка H2: админ-хаб ≠ воронка; `completed` менеджера ≠ выплата; COUNT реф-операций ≠ ref cost.
