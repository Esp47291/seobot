# Риски и митигации

Не предлагаем обход ToS площадок. Риск в том, что **текущий продукт легко прочитать как накрутку** — это чинить позиционированием и правилами, не «схемами».

| Риск | Почему реален | Митигация | P |
|---|---|---|---|
| ToS Яндекс/2ГИС/Google | Отзывы за деньги = серая зона площадок | Позиционирование: реальный визит, свой опыт, отказ в объёме «ради рейтинга». Стоп при претензии | P0 |
| Репутация бренда | Rules copy «платим за отзывы» | Переписать (COPY_SYSTEM). Сайт — процесс, не звёзды | P0 |
| Фрод исполнителей | Скорость, second-acc, реф-веер | Сигналы, новички в ручную очередь, hold первого вывода | P0 |
| Ручные выплаты | Касса + человеческий фактор | Ежедневный inbox WD, лимит pending ₽, сверка | P0 |
| MemoryStorage | Потеря сдачи | Redis/DB | P0 |
| Очередь модерации | Тишина → отток и повторные скрины | SLA-текст + сортировка stale | P1 |
| Реферал 25% | Съедает маржу | P_c с запасом; не платить за join | P1 |
| Прокси-секрет в git | rules.py | Вынести, ротировать | P1 |
| Рассылка всем | Блоки бота | Сегмент, 1–2/день, польза | P1 |
| Две ветки кода | master vs patch-15 | Документируем patch-15; не мержить master-логику вслепую | P1 |
| Нет сайта | Нет B2B входа | Лендинг неделя 2–3 | P1 |
| Юридический (персональные данные скринов/реквизитов) | Храним фото и карты | Privacy, доступ только staff, срок хранения — назначить | P1 |
