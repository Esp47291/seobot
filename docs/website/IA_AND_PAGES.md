# IA сайта Job Inside

Сайта в репо нет. Два оффера на одном домене, без смешения «заработок» и «для бизнеса» в одном герое.

## Карта

```
/                  лендинг: герой для бизнеса + якорь исполнителям
/business          процесс, площадки, правила для заказчика, CTA
/executors         как работать, правила, вывод, FAQ исполнителей
/rules             безопасность и правила (оба)
/faq               общее
/contact           заявка бизнеса + поддержка исполнителей
/legal/privacy
/legal/terms
```

Позже: `/status` не нужен публично. Кабинет заказчика — не в v1.

## Навигация

`Бизнесу` · `Исполнителям` · `Правила` · `Контакты`  
CTA справа: «Оставить заявку» (бизнес). Вторичная: «Открыть бота».
