# IA сайта Job Inside

Сайта в репо нет. **Один домен, две аудитории — на разных URL.** Герой `/` только для бизнеса. Исполнитель не конкурирует за CTA в шапке.

## Карта v1

```
/                  лендинг бизнеса: герой + процесс + форма #lead
/#how              якорь «как это работает» (5 шагов)
/#lead             форма заявки
/business          v1 = редирект на /#how  (не плодить тонкий дубль)
/executors         единственная страница «заработок»: правила, вывод, CTA бота
/rules             безопасность и правила (оба, один текст)
/faq               общее; бизнес и люди — разные H2
/contact           = /#lead + саппорт исполнителя (SUPPORT_URL)
/legal/privacy
/legal/terms
```

Не в v1: `/app`, `/login`, `/status`, кабинет заказчика, карта «50 городов», блог.

## Навигация

Шапка `/`: `Как это работает` · `Правила` · `Контакты`  
CTA справа **только** «Оставить заявку».  
Пункт «Исполнителям» — в футере, не в шапке героя (иначе снова два оффера в 10 секундах).

На `/executors` шапка другая: `Правила` · `Бизнесу` (ссылка на `/`) · CTA «Открыть бота».

## Что не обещать маршрутами

| Идея | Почему нет |
|---|---|
| `/dashboard` для заказчика | В patch-15 нет сущности заказчика; заказ ведёт менеджер |
| `/signup` бизнеса в бота | `/start` = коридор исполнителя |
| Публичный `/jobs` | Слоты только внутри бота после правил и gate канала |
| «Личный менеджер 24/7» | Роль manager есть, SLA ответа нет в данных |

## События по URL

| URL | Событие |
|---|---|
| `/` | `landing_view` |
| submit `#lead` | `biz_lead` |
| `/executors` → t.me | `executor_bot_click` |
