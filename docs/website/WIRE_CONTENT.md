# Wire content секций

## Для заказчиков (`/business`)

1. Проблема: карточка пустая или молчит — клиент не доходит.  
2. Процесс: бриф → слоты → проверка → отчёт.  
3. Что входит / что нет: нет обещания рейтинга и обхода ToS площадок.  
4. Гео: исполнители ближе к точке — меньше мусорных работ.  
5. FAQ бизнеса: сроки, кто пишет текст, кто модерирует, как считаем объём.  
6. CTA: город, площадки, контакт.

## Для исполнителей (`/executors`)

1. Что это: задания, не «лёгкие деньги».  
2. Как платят: баланс после **принятия**, вывод заявкой, минимум из настроек бота (default 20 ₽ — проверить факт).  
3. Правила: свой опыт, свой город, честный скрин.  
4. Реферал: % с принятых заданий, не с клика.  
5. CTA: открыть бота.

## FAQ (общее)

- Кто проверяет работы? Админ/менеджер, вручную.  
- Когда деньги? После accepted + заявка на вывод, срок = ASSUMPTION из processed_at.  
- Можно с нескольких аккаунтов? Только через отдельную модерацию second-account, не как фича обхода.  
- Заказчику: можно ли «гарантированно 50 отзывов»? Нет, работаем объёмом принятого и правилами площадок.

## Безопасность и правила

Качество, запрет накрутки и чужих аккаунтов как услуги, хранение скринов для спора, блок при нарушении.  
Исполнитель и заказчик видят **одни и те же** красные линии.

## Контакты

Форма бизнеса (город, площадки, имя, Telegram).  
Исполнитель: SUPPORT_URL из env / help_text бота.
