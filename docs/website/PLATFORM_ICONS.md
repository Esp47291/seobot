# Площадки на сайте

Показывать только те, с которыми **умеем работать процессом** (задание → доказательство → проверка).  
В коде patch-15 платформа — свободная строка; дефолтные мин. цены: Яндекс 130 / Google 35 / 2ГИС 12 (это дефолты настроек, не прайс сайта).

## Порядок блока

1. Яндекс Карты — «Карточка организации, отзыв после визита»  
2. 2ГИС — «Локальная карточка»  
3. Google Maps — «Там, где точка в Google»  
4. Другие — «По запросу, если есть прозрачный процесс проверки» (не обещать всё)

Не тащить 12 логотипов «для солидности».

## Подписи

Коротко, без «накрутим». Формат: *где видят вас клиенты* + *как подтверждаем работу*.

## Trust «как это работает»

1. Бриф точки и площадок  
2. Слот исполнителю в городе рядом  
3. Скрин / доказательство  
4. Модерация  
5. Отчёт заказчику, оплата принятого  

Исполнителю на соседней странице те же 5 шагов, акцент на балансе и правилах.
