# Visual direction

Не дефолтный AI-look (Inter + фиолетовый градиент + блюр).  
Атмосфера: **вечерняя карта города** — тёплый свет витрин, холодный асфальт, уверенно и спокойно.

## Направление

- Сетка как схема района, не как SaaS-иллюстрация 3D.
- Фото: витрины, вход, табличка часов — не стоковые «рукопожатия».
- Иконки площадок — монохром + один акцентный пигмент, не радуга логотипов.

## CSS-переменные (черновик)

```css
:root {
  --bg: #12160f;
  --bg-elev: #1c2218;
  --ink: #f3efe4;
  --ink-dim: #b7b09e;
  --accent: #d4a04a;      /* латунь/вывеска, не electric yellow */
  --accent-2: #3d6b5a;    /* мох / вывеска аптеки */
  --line: #2a3126;
  --danger: #c45c4a;
  --ok: #7ea36b;
  --font-display: "Source Serif 4", "PT Serif", serif;
  --font-body: "Manrope", "Onest", sans-serif;
  --radius: 6px;          /* почти прямой угол, как табличка */
}
```

## Типографика

- Заголовки: антиква с характером (Source Serif 4 / Fraunces light).
- Текст: Manrope или Onest, 17–18px, inter-line 1.45.
- Не Inter, не Montserrat, не «все капсом».

## Motion (2–3 идеи)

1. Герой: лёгкий параллакс сетки улиц (очень тихо, 200–400ms).
2. CTA: заливка «как включается вывеска», не bounce.
3. Блок площадок: иконки проявляются по одной, без карусели.
