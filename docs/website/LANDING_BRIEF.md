# Landing brief — первый экран

Один оффер, один подзаголовок, один главный CTA. Без карусели выгод.

## Герой (B2B — платящий)

**Бренд:** Job Inside  
**Оффер:** Локальное присутствие на картах — через понятный процесс и проверку работ, не через серые схемы.  
**Подзаголовок:** Бриф точки, слоты исполнителям, модерация скринов, отчёт по факту. Вы платите за принятую работу.  
**CTA:** Оставить заявку  
**Вторичная:** Как это работает ↓

Не писать: «накрутим отзывы», «гарантия 5.0», выдуманные кейсы.

## Под героем (не в первый вьюпорт)

Короткий блок исполнителю: «Ищете задания? Откройте бота — правила и вывод внутри.» Ссылка на `/executors`.

## Доказательства без цифр из воздуха

Пока нет кейсов — процесс: 4 шага + «модерация вручную» + «выплаты исполнителям с баланса».  
Цифры (объём, города) — только когда снимем из БД.
