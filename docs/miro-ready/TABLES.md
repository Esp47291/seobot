### Unit: take vs no_take (не потерянная выручка)

| Исход | Деньги | Не делать | Действие |
|---|---|---|---|
| take | CM1 после P_c и credited | называть ₽ до UNIT-01 | скрипт 9: N, потом P |
| no_take | EV ≤ 0 | скидка / «дешёвый пилот» / слот | скрипт 16, без счёта |
| hold | CM1 нет | обещать дату без supply | ждать слоты |

## Site + Sales scripts summary

| Что | Одна строка | CTA / цель |
|---|---|---|
| Герой `/` | Присутствие на картах. Прозрачный процесс. | Только «Оставить заявку» |
| CTA2 в герое | нет (H3: бот уводит B2B) | бот — `/executors` + футер |
| Trust-чипы | Ручная модерация · гео рядом · оплата за принятое | без фейковых N |
| Форма | Имя, город, Telegram (+ чипы площадок) | `biz_lead` |
| Закрытие заявки | менеджер → TaskItem, кабинета нет | не self-serve |
| Исполнители | Правила и вывод, без лёгких денег | Открыть бота |
| Скрипт 1 холод | Карточка, без URL, 1 вопрос | «бриф» |
| Скрипт 13 inbound | `#lead`: не дублировать форму | Q1 точка + Q3 ожидание |
| Скрипт 14 накрутка | ToS: не продаём отзыв как товар | процесс или отказ |
| Скрипт 15 шаблон | Prebuilt не слать клиенту | отказ текста |
| Скрипт 16 no-take | После серого Q3 | без счёта |
| Скрипт 8 срочный объём | Не берём квоту | отказ-качество |
| Скрипт 9 close | 14 дней, N принятых, P | фиксация |
| Qualifier | берём = визит+проверка+темп | иначе 16 |
| Тест нед.1 | 15 касаний одного города / одного ICP | ≥1 бриф, 0 URL в 1-м DM |
| Канал нед.1 | outbound карты, скрипт 1 | не broadcast бота |
| Исход касания | sent→reply→brief→take\|no_take\|hold\|mute | no_take ≠ проигрыш |
| Город | сначала venue_city / набор supply | иначе hold, не слот в никуда |
| Нед.3 партнёр | 5 агентств, URL в подписи | стоп если stuffing; не чужой $/мес |
| Запрет | серый take «загрузить» исполнителей | EV ≤ 0, C_mod↑ |
| Copy бот /start | процесс + 2 роли | не «начнем зарабатывать» |
| Copy правила | визит, свой текст, баланс после accepted | не «платим за отзывы»; нет прокси в тексте |
| Copy деньги | «на балансе» ≠ «перевели» | не «принят и оплачен» до credited / WD paid |
| Copy реферал | % с принятых | не пассив, не за вход |
| Copy канал | как скрипт 1 | не прайс и не рейтинг |
| Copy prebuilt | не слать исполнителю | не «смягчить и отправить» |
