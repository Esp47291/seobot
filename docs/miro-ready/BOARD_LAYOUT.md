# Доска «Job Inside Business OS»

Порядок фреймов слева направо, сверху вниз. Завтра копипаст из TABLES.md и MIRO-READY секций файлов.

```
[0. Today] DAILY + топ-5 + рекомендация владельцу
[1. Product fact] Capability map (статус зон)
[2. UX] /start → задание → статус → кабинет → вывод
[3. Journeys] 3 дорожки: исполнитель / менеджер / админ
[4. Analytics] Taxonomy + воронки F1–F5
[5. Unit] таблица экономии + оффер
[6. Site] герой + IA + площадки
[7. Sales] скрипты 1–10 + недельные тесты
[8. 30 days] недели 1–4
[9. Risks] ToS / фрод / касса / FSM
[10. Sources] 5 ссылок research
```

Цвета фреймов (к VISUAL_DIRECTION): фон тёмный, акценты латунь = P0, мох = сделано.
